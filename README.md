# terralog-crypto

The end-to-end encryption core of [Terralog](https://terralog.be), a travel journal app,
published so that it can be reviewed.

This is not a new library. It is an extraction of the code that runs in the app today,
rewritten as pure functions with no dependency. It produces the same bytes as the app: the
test vectors in `test/vectors.json` were generated by running the app's own code, and the
app decrypts what this module encrypts (and the reverse).

What it covers:

| Part | App name | What it does |
|---|---|---|
| Notebook derivation | `rtDeriverCarnet` | first name + 6-digit code + passphrase → address, owner token, master key (PBKDF2-SHA256, 600 000 iterations) |
| Trip derivation | `rtDeriverVoyage` | master key + frozen trip identity → trip address and token |
| Reading material | `rtDeriverMatiereLectureV2/V1` | the value carried after `#k=` in a share link |
| Content key | `coffreCleDepuis` | AES-256-GCM key from a reading material |
| Text fields | `coffreChiffrerTexte` | `RTC1:` + base64url(IV ‖ ciphertext ‖ tag) |
| Media | `coffreChiffrerBlob` / `…V2` | `RTC1` (written) and `RTC2` (read only) binary formats |
| Backups | `rtSauve…` | key envelope under a passphrase, chunked `.tlg` files, `TLGC1` container |
| Server fingerprints | `lien_empreinte`, `prop_empreinte` | what the relay stores instead of links and tokens |

What it does not cover: the relay (server), the user interface, the service worker that
serves decrypted media, and payments. Those stay closed for now.

The format specification, with its known limits, is in `SPEC.md`.

## Use

```js
import { createTerralogCrypto } from './src/terralog-crypto.mjs';

const tc = createTerralogCrypto({
  subtle: crypto.subtle,
  getRandomValues: (a) => crypto.getRandomValues(a),
});

const { link, ownerToken, master } = await tc.deriveNotebook('Ana', '123456', 'a long passphrase');
const key = await tc.contentKey(await tc.readingMaterialV2(master, link));
const sealed = await tc.encryptText(key, 'Hello from Bruges');
```

## Tests

```
npm test        # Node 20 or later, no install needed
```

- `test/vectors.test.mjs`: known answers produced by the app code.
- `test/properties.test.mjs`: what must fail does fail (wrong key, changed byte, truncation,
  swapped chunks, forged headers, hostile iteration counts, another file's identity).

## Reporting a problem

Please open an issue, or write to the address given in
https://terralog.be/.well-known/security.txt for anything that should not be public.
